## 🔴 高风险问题

### 1. RSA公钥硬编码泄露
**位置**: `settings.js:8-16`
**问题**: RSA公钥直接写在源代码中
```javascript
publicKey: '-----BEGIN PUBLIC KEY-----\n' +
    'MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEAtEdgPwBkPuulvFSr0ESP\n' +
    // ... 完整的公钥
```
**影响**:
- 加密机制形同虚设
- 攻击者可利用公钥分析加密算法
- 生产环境密钥暴露

**修复建议**:
```javascript
// .env 文件
VUE_APP_PUBLIC_KEY=your_public_key_here

// settings.js
const settings = {
    publicKey: process.env.VUE_APP_PUBLIC_KEY || '',
}
```

### 2. 大量敏感调试信息泄露
**位置**: 多个文件
**问题**: 生产环境仍会输出敏感调试信息

**主要问题文件**:
- `src/views/base/Login.vue:35-49` - 登录过程详细信息
- `src/router/index.js:131,144` - 路由初始化信息
- `src/utils/request.js:43,55` - API请求响应详情

**修复建议**:
```javascript
// 创建全局日志管理
// src/utils/logger.js
const logger = {
    log: process.env.NODE_ENV === 'development' ? console.log : () => {},
    error: console.error,
    warn: process.env.NODE_ENV === 'development' ? console.warn : () => {}
};

// 在入口文件配置
if (process.env.NODE_ENV === 'production') {
    console.log = () => {};
    console.info = () => {};
    console.warn = () => {};
    console.debug = () => {};
}
```

### 3. CSRF防护完全缺失
**位置**: `src/utils/request.js`
**问题**: 所有请求都没有CSRF保护
```javascript
instance.interceptors.request.use(config => {
    config.headers['crabapples-token'] = storage.getToken()
    // 缺少CSRF token
})
```
**影响**:
- 易受跨站请求伪造攻击
- 恶意网站可执行未授权操作

**修复建议**:
```javascript
// 请求拦截器添加CSRF token
instance.interceptors.request.use(config => {
    // 从meta标签获取CSRF token
    const csrfToken = document.querySelector('meta[name="csrf-token"]')?.getAttribute('content');
    if (csrfToken) {
        config.headers['X-CSRF-TOKEN'] = csrfToken;
    }

    config.headers['crabapples-token'] = storage.getToken()
    return config
})
```

## 🟡 中风险问题

### 4. Token存储不安全
**位置**: `src/store/storage.js`
**问题**: 使用localStorage存储token
```javascript
getToken: () => localStorage.getItem('TOKEN'),
setToken: (token) => localStorage.setItem('TOKEN', token),
```
**影响**:
- localStorage易受XSS攻击
- Token永不过期
- 无法检测Token篡改

**修复建议**:
```javascript
// 使用更安全的存储方式
const storage = {
    setToken: (token) => {
        // 加密token
        const encrypted = btoa(token + '|' + Date.now());
        sessionStorage.setItem('TOKEN', encrypted);
        sessionStorage.setItem('TOKEN_EXPIRES', Date.now() + 24*60*60*1000);
    },

    getToken: () => {
        const encrypted = sessionStorage.getItem('TOKEN');
        const expires = sessionStorage.getItem('TOKEN_EXPIRES');

        if (!encrypted || Date.now() > expires) {
            this.logout();
            return null;
        }

        const [token] = atob(encrypted).split('|');
        return token;
    }
}
```

### 5. 硬编码配置信息
**位置**:
- `settings.js:2` - API地址硬编码
- `vue.config.js:101,116` - 代理地址硬编码

**问题**:
```javascript
baseUrl: 'http://localhost:9093/', //测试环境
target: 'http://localhost:9093/', //代理配置
```
**修复建议**:
```javascript
// 使用环境变量
const settings = {
    baseUrl: process.env.VUE_APP_API_BASE_URL || 'http://localhost:9093/',
    isDebug: process.env.NODE_ENV === 'development',
}

// vue.config.js
proxy: {
    '/api': {
        target: process.env.VUE_APP_PROXY_TARGET || 'http://localhost:9093/',
    }
}
```

### 6. 依赖安全漏洞
**位置**: `package.json`
**问题**: 使用过时版本的依赖
- `vue: 2.6.14` - 存在已知安全漏洞
- `axios: 1.11.0` - 需要安全更新
- `ant-design-vue: 1.7.8` - 可能存在安全问题

**修复建议**:
```bash
# 执行安全审计
npm audit

# 修复安全漏洞
npm audit fix

# 更新关键依赖
npm update vue axios ant-design-vue
```

### 7. 开发服务器配置不安全
**位置**: `vue.config.js:94`
**问题**: 允许所有主机访问开发服务器
```javascript
host: "0.0.0.0",
```
**修复建议**:
```javascript
devServer: {
    host: process.env.DEV_HOST || 'localhost',
    allowedHosts: [
        'localhost',
        '127.0.0.1',
        '.yourdomain.com'
    ]
}
```

## 🟢 低风险问题

### 8. 错误信息过度暴露
**位置**: `src/utils/request.js:55-60`
**问题**: 向用户暴露详细错误信息
```javascript
notification.error({
    message: error.code,
    description: `服务器异常：${error.response.status}`,
})
```
**修复建议**:
```javascript
const isProduction = process.env.NODE_ENV === 'production';
const errorMsg = isProduction ? '服务暂时不可用，请稍后重试' : error.message;

notification.error({
    message: '请求失败',
    description: errorMsg,
})
```

### 9. 路由配置潜在问题
**位置**: `src/router/index.js:156`
**问题**: 动态路由添加通配符过于宽泛
```javascript
newRouter.push({path: '*', redirect: '/404', hidden: true})
```
**修复建议**:
```javascript
// 更精确的404路由配置
newRouter.push({
    path: '*',
    redirect: '/404',
    hidden: true,
    beforeEnter: (to, from, next) => {
        // 记录无效访问
        console.warn('无效路由访问:', to.path);
        next('/404');
    }
})
```

### 2. 安全中间件配置
```javascript
// src/middleware/security.js
export default {
    install(Vue) {
        // 防止XSS
        Vue.prototype.$sanitize = (str) => {
            const div = document.createElement('div');
            div.textContent = str;
            return div.innerHTML;
        };

        // CSP Header设置（需要后端配合）
        const meta = document.createElement('meta');
        meta.httpEquiv = 'Content-Security-Policy';
        meta.content = "default-src 'self'; script-src 'self' 'unsafe-inline'";
        document.head.appendChild(meta);
    }
}
```
